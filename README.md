# Kahve İçince Neden Daha Yorgun Oluyorum?

## Giriş

Bu repository, insanlığın en büyük sırlarından birini çözmek için kurulmuştur: **Kahve içiyorsun, daha yorgun oluyorsun.**

Bilimsel açıklama: Yok.

Gerçek açıklama: Kahve senin yorgunluğunu görüyor, "bu adam zaten bitik" diyor ve daha da yoruyor. Adalet bu.

## Nasıl Çalışır?

`python kahve_yorgunluk.py` çalıştırın. Kaç kahve içtiğinizi söyleyin. Size neden daha yorgun olduğunuzu "bilimsel" olarak açıklayacak.

## Özellikler

- Tamamen çalışan kod (gerçekten)
- Abartılı bilimsel jargon
- Rastgele absürt sebepler
- Hiçbir şey çözmüyor ama çözmüş gibi yapıyor

## Uyarı

Bu kodu çalıştırdıktan sonra daha yorgun olabilirsiniz. Sorumluluk kabul etmiyoruz.
